## 1. 背景与问题

批次二A 修正单位后，回测盈亏 cumPnL 仍只记**期货对冲腿**：负债端雪球现值不逐日盯市，
导致归因恒等式 `cumPnL = Γ + Θ − Cost + Residual` 中的 Residual 被迫吸收整个负债现值变化
ΔV×N（2024H1 daily 为 −41.0 万），|Residual/cumPnL| 六格 167%~488%，无法收窄（ISSUES-6）。

v7.1.0 的根治：回测升级为**账本口径**——账本 = 空头雪球负债 + Delta 对冲头寸，逐日双腿入账，
归因恒等式落在账本上，未归因项 ε 回归其应有含义：**真离散对冲误差**。

| 符号 | 定义 | 单位 | 来源 |

| 负债金额 | V_t × N | 元 | |
| delta | ∂V/∂S（CRN 差分，表内原值） | 名义比例/点 | greeks.js |
| gamma | ∂²V/∂S² | 名义比例/点² | greeks.js |
| theta | V(T−12/252) − V(T)（nSteps 不变，dt 缩小，严格 CRN） | 名义比例/12 交易日 | greeks.js |
| h_t | 对冲持仓 = delta×N | 份 | 批次二A |
| V(T) 定价 | priceWithNormals，CEV 局部波动 + BB 桥 | 每元名义 | pricing.js |

符号约定（卖方 = 雪球发行商，空头负债方）：
- **负债腿**：卖方欠投资者 V×N。负债现值**下降**是卖方收益：当日负债腿损益 = **−ΔV_t × N**，ΔV_t = V_{t+1} − V_t。
- **对冲腿**：卖方持 h 份股指期货多头（delta>0 时），当日损益 = h × dS（元）。
- **theta 方向**：theta = V(T−12/252) − V(T) < 0（票息现值随期限缩短而减少）意味着负债每交易日
  缩水 −theta/12（每元名义），卖方**收入** −theta×N/12（元/交易日）。Greeks 卡片展示的
  「Theta 金额 = theta/12×N」是**负债变动**方向（负值=负债缩水），账本 Θ 归因取反号（正值=卖方收入），
  两者一字不差地对偶，验收标准 3 的方向一致性以此核对。

## 3. 逐日账本恒等式

对每个交易日 t（移动 S_t → S_{t+1}）：

```
账本当日盈亏_t = 对冲腿_t + 负债腿_t − 当日成本_t
             = h_t·dS_t × 1 − (V_{t+1} − V_t) × N − cost_t
```

- 对冲腿 h_t·dS_t：与批次二A 修正后的 cumPnL 累加项**同一语句、逐位一致**（回归锚点）。
- 负债腿盯市：V_t 与 V_{t+1} 各一次查表 PV 插值（与 Greeks 同网格同 CRN，零额外模拟）。
- 成本：调仓日 |Δdelta|×N×S_t×costRate（日内模式为子时段累加，同引擎）。

## 4. Taylor 展开与归因恒等式

把 ΔV_t = V(S_{t+1},T_{t+1}) − V(S_t,T_t) 在**移动起点 (S_t, T_t)**（即当日查表状态）展开：

```
ΔV_t ≈ delta_t·dS_t + ½·gamma_t·dS_t² + theta_t/12   （每元名义；高阶项余项 R_t）
```

代入账本恒等式（注意对冲腿用的持仓是**前一日调仓价** h_{t−1} = delta_{t−1}×N，见 §5 时序）：

```
账本_t = delta_{t−1}·dS_t·N − delta_t·dS_t·N − ½·gamma_t·dS_t²·N − theta_t·N/12 − cost_t − R_t·N
       = (delta_{t−1}−delta_t)·dS_t·N − ½·gamma_t·dS_t²·N − theta_t·N/12 − cost_t − R_t·N
```

一阶项近似对消（残差 (delta_{t−1}−delta_t)·dS·N 为二阶小量，归入 ε）。于是定义**账本归因四项**：

| 归因项 | 定义 | 单位 |
|---|---|---|
| Gamma 归因 | **−½·gamma_t·dS_t²·N**（对每个交易日累加） | 元 |
| Theta 归因 | **−theta_t·N/12**（每交易日，与卡片 g/12×N 口径对偶取反号） | 元 |
| 成本 | −totalCost | 元 |
| 未归因项 ε | **bookPnL − Gamma归因 − Theta归因 + totalCost** | 元 |

**归因恒等式（精确闭合，逐位）**：

```
bookPnL = Gamma归因 + Theta归因 − totalCost + ε
```

ε 不再含负债现值变化（已入账），其构成（§5 逐项对应）：
1. **离散对冲误差**：(delta_{t−1} − delta_t)·dS·N —— 对冲腿用前一日调仓价、负债腿一阶项用当日
   delta 的错位；以及日频/周频/月频调仓粒度本身的 Delta 漂移；
2. **Taylor 高阶项**：dS³ 以上项与月度敲出观察日处 V(S,T) 的条件跳变（观察日越过时 KO 判定重置，
   表内以期限插值平滑，跳变能量落入 R_t）；
3. **双线性插值平滑误差**：V 与 Greeks 同为 24×24 网格分片双线性，格内真实曲率与交互项
   （∂²V/∂S∂T）在 p 与 delta/gamma 之间的插值失配；
4. **MC 残余噪声**：4096 路径 CRN 跨期截断后逐列残差（同列严格 CRN，跨列部分相关）。

其中 1 是「离散对冲误差」的本体；2–4 是度量的代价，随窗口放大以 √n 级累积（非 ∝n），
量级见 §8 体检表。

## 5. 引擎时序约定（实现锚点）

回测循环第 i 次迭代处理移动 S_i → S_{i+1}（i = 0..n−2）：

| 量 | 取值 | 说明 |
|---|---|---|
| 查表 g_i | lookup(ratio_i, T_i) | 移动起点状态：delta/gamma/theta/**p** 同源 |
| 查表 gNext | lookup(ratio_{i+1}, T_{i+1}) | 移动终点盯市值；与下一迭代 g 完全同点（逐位同值） |
| 对冲腿 | position×dS×N，position 为**上一迭代调仓结果** | legacy 时序（golden-v7-scaled 锚点，不动）；首日 position=0 |
| 调仓 | 移动结算后按 g_i.delta 调至目标（daily 每日 / weekly 每 5 日 / monthly 每 21 日；intraday2/4 为子时段调仓） | legacy |
| 负债腿 | −(gNext.p − g_i.p)×N | 与对冲腿同一移动精确配对 |
| 归因 Greeks | g_i（**移动起点日**） | Taylor 展开中心；与 legacy 腿级归因的「前一日 Greeks」不同，属新字段 |
| path[] | 增记 bookCumPnL（账本累计）与 liabCumPnL（负债腿累计） | 图表与 Bootstrap 用 |

关键决策记录：
- **盯市配对**：负债腿在迭代 i 内用两次查表（起点/终点）结算，不用「下一迭代回填」，保证
  path[i].bookCumPnL 是精确的期末累计（最后一次迭代 gNext 即最末盯市，无需循环外补点）。
- **归因用起点日 Greeks**：Taylor 展开的正确中心；批次二A 探针已证当日口径残差（+47.5 万）
  显著小于前一日口径（+89.2 万）。腿级旧字段（gammaPnL/thetaPnL）保持前一日口径不动。
- **期限轴端点**：循环尾段 T_t = max(1, …) 触发期限轴下端钳位（tenorGrid[0]=2 月），
  最后数日盯市值与 Greeks 同在 2 月角点，属表结构既定约定，ε 吸收其边界效应。
- **月度观察日跳变**：表内结构按「现点重发行」标记（barrier 相对发行价固定），观察日重置
  体现为期限维度的条件变化，经双线性插值平滑后进入 ε（第 2 项）。

### 8.1 ε 分解取证：ε = L − TE（六格全部精确闭合，残差 < 1e-6 元）

tools/book-checkup.mjs 对每格输出 L 与 TE 分解（L = cumPnL − Σ当日δ·dS·N，TE = ΣΔV·N − Σ当日δdS·N − Σ½γdS²N − Σθ/12·N）：

|---|---:|---:|---:|
| 2024H1 daily | +576,232 (+5.76%N) | −46,489 (−0.46%N) | 622,721 |
| 2024H1 weekly | −565,810 (−5.66%N) | −46,489 (−0.46%N) | −519,321 |
| 2024H1 monthly | +399,972 (+4.00%N) | −46,489 (−0.46%N) | 446,460 |
| 2025H1 daily | +25,401 (+0.25%N) | −166,841 (−1.67%N) | 192,242 |

结论：
- **L 的来源**：legacy 引擎时序——迭代 i 的调仓发生在当日盈亏结算之后，移动 S_i→S_{i+1} 由 δ(S_{i−1}) 对冲
  （首日 position=0），相对「当日收盘调仓」存在一日滞后。该时序被 golden-v7-scaled 腿级键逐位锁定（铁律 1），
  账本层不可修正。V 型窗口（2024H1 大跌反弹）中滞后与行情同向共振，L 达 ±(4~6)%N；平稳窗口（2025H1）L 仅 ±0.3%N。
- **TE 的来源**：§4 ε 组成 2/3/4（高阶项+观察日效应、双线性插值平滑、θ 12 日差分线性摊销与期限轴 2 月钳位、
  MC 残余噪声）。自适应网格下 2024H1 仅 −0.46%N；2025H1 −1.67%N（账本基数小，占比被动放大）。
- **未达标的定性**：非推导或实现错误——恒等式 ε = L − TE 六格精确闭合、golden 三层锁逐位通过（见 §7 与
  tests/golden-v7-book.json）、三日验签 Taylor 交叉核对相符；|ε/book| ≥50% 的三格（2024H1 weekly、2025H1
  daily/weekly）均系「账本基数小（5.3%N / 3.8%N）而 L 或 TE 与之同量级」的分母效应，展示层已按阈值红字标注。
- 与批次二A 对比：未归因项绝对量从 ±(11~23)%N（residual 含整个负债腿）收窄至 ±(1.5~6.2)%N（真误差），
  含义净化为离散对冲误差；比值口径因分母换为账本盈亏而重立阈值（<20 优秀 /<50 可接受 /≥50 超标红字）。
